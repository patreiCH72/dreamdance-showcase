# Dream Dance Showcase

Statische Demoseite für eine neue Website der Tanzschule Dream Dance im Tanzforum Aarau. Kein CMS, kein Backend, keine Datenbank.

Die Seite richtet sich an Eltern und Tänzerinnen: Freude am Tanz, das Kursangebot und die Podestplätze der Competition-Gruppen Little Dreamers und Newborns.

## Seiten

- `/` Startseite mit Claim, Philosophie, Erfolgen und Team-Vorschau
- `/kurse` Angebot, Stufen und Unterrichtstage
- `/erfolge` Resultate, Coach, Lehrerteam, Junglehrer und Tanzvorstellung

Anmeldung, Preise und Stundenplan verlinken auf [dreamdance.ch](https://www.dreamdance.ch). Die Fotos sind Stimmungsbilder und zeigen weder Team noch Schülerinnen.

## Lokal

```bash
npm install
npm run dev
```

Produktionsbuild: `npm run build`.
